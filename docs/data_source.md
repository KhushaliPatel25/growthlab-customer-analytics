
# GrowthLab — Dataset Source

## Dataset
eCommerce Events History in Cosmetics Shop

## Provider
REES46

## Source
https://www.kaggle.com/datasets/mkechinov/ecommerce-events-history-in-cosmetics-shop

## Source files
- 2019-Dec.csv.gz
- 2020-Jan.csv.gz

## Analysis period
December 2019 – January 2020

## Available event attributes
- Event timestamp
- Event type
- Product ID
- Category ID and category code
- Brand
- Price
- User ID
- User session

## Intended analysis
- Customer purchase funnel
- Customer activity
- Retention cohorts
- Customer segmentation
- Revenue and conversion analysis

## Experimentation note
A/B testing will use a separate simulated
randomized experiment. The source event data
does not contain experiment assignments.

## Data handling
Original source files are stored locally
in data/raw and excluded from GitHub.
